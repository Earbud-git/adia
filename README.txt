Cara membuka di komputer:
  Klik dua kali index.html untuk membukanya dengan browser.

Cara mengunggah ke GitHub Pages:
  1. Buka repository GitHub Anda.
  2. Unggah index.html dan seluruh folder assets ke akar repository.
  3. Pastikan folder assets dan index.html berada sejajar.
  4. Di Settings > Pages, pilih Deploy from a branch, lalu main dan /(root).
  5. Tunggu sampai GitHub Pages menampilkan tautan website.

Penting: Nama file dan folder menggunakan huruf kecil tanpa spasi. Jangan ubah nama file tanpa memperbarui alamat di index.html.

Catatan: Tombol Kirim Pesanan dalam kode awal hanya menampilkan pesan pop-up di browser. Belum ada server pemroses pesanan.
